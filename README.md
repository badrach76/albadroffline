# وحدة إنتاج زيت الزيتون البدر — نسخة محلية أولية

## ما الذي تتضمنه هذه النسخة؟
- لوحة قيادة.
- تسجيل مبيعات الزيت مع رقم الحصة والكمية والثمن والأداء.
- تسجيل خدمات الطحن، مع تعريفة افتراضية 0.70 درهم/كلغ.
- سجل الإنتاج والحصص ومردودية الزيت والمرجان والفيتور.
- ملفات الزبائن.
- المصاريف والصيانة، بما فيها الكهرباء والتعليب.
- العمال والأجور وأيام العمل والتسبيقات.
- حركات المخزون.
- صندوق، تقارير، وطباعة.
- نسخ احتياطي JSON واسترجاعه.
- تخزين محلي داخل المتصفح (IndexedDB).

## التشغيل
لضمان خصائص التطبيق التقدمي والعمل دون اتصال، شغّل المجلد من خادم محلي بسيط أو ارفعه مرة واحدة إلى استضافة HTTPS:
- يمكن استخدام VS Code مع إضافة Live Server.
- أو تشغيل `python -m http.server 8000` داخل المجلد ثم فتح `http://localhost:8000`.
- بعد فتح التطبيق مرة أولى، يمكن تثبيته من قائمة المتصفح على الهاتف أو الحاسوب، ثم تشغيله دون إنترنت.

فتح `index.html` مباشرة من مدير الملفات قد يسمح ببعض الوظائف، لكنه لا يضمن تثبيت التطبيق أو Service Worker.

## حفظ البيانات
البيانات تحفظ في المتصفح وعلى الجهاز نفسه. لا توجد مزامنة بين الهاتف والحاسوب في هذا الإصدار (حسب الاختيار: local). إذا مسحت بيانات المتصفح أو غيرت الجهاز فقد تفقد البيانات؛ لذلك استخدم «الإعدادات والنسخ» لتنزيل نسخة احتياطية دورية، ثم استرجعها عند الحاجة.

## حدود النسخة الأولى
هذه نسخة تشغيل أولية وليست نظاماً محاسبياً معتمداً. لا تُحسب الأرباح النهائية أو تكلفة الإنتاج الكاملة تلقائياً بعد. كما أن المبيعات لا تخصم تلقائياً من مخزون الزيت، وحركات الصندوق لا تُنشأ تلقائياً من عمليات البيع والطحن. ينبغي تطوير هذه الروابط قبل اعتمادها في المحاسبة اليومية النهائية.

## التطوير التالي المقترح
1. ربط البيع والطحن والصندوق آلياً ومنع احتساب العملية مرتين.
2. حساب رصيد مخزون زيت الوحدة وزيت الزبائن بشكل منفصل.
3. كشف حساب الزبون حسب الحصص.
4. ترقيم تلقائي للحصص والوصولات.
5. طباعة وصل بيع ووصل طحن بتصميم رسمي.
6. إدارة دورات أجور العمال شهرياً.
7. تحسين التقارير الموسمية وتحليل المردودية والتكاليف.
