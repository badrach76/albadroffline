# منصة وحدة إنتاج زيت الزيتون البدر — الإصدار المطوّر 4

نظام محلي (Local-first) باللغة العربية، مناسب للهاتف والحاسوب، لمستخدم واحد وموسم 2026-2027.

## تشغيل المنصة
1. فك ضغط الملف.
2. شغّل المجلد عبر خادم محلي مثل VS Code Live Server أو `python -m http.server 8000`.
3. افتح العنوان المحلي في متصفح حديث، ثم ثبّت التطبيق من قائمة المتصفح (Install app / Add to Home Screen).
4. بعد تحميل الملفات وتثبيت Service Worker أول مرة، يمكن فتحه دون اتصال بالإنترنت.

فتح `index.html` مباشرة من مدير الملفات قد لا يفعّل التثبيت أو التخزين المؤقت دون اتصال. لا توجد خدمة سحابية ولا مزامنة بين الأجهزة في اختيار local.

## الوحدات الحالية
- لوحة قيادة للمبيعات والطحن والمصاريف والديون والإنتاج.
- بيع الزيت: رقم وصل تلقائي، رقم الحصة، الزبون، نوع الزيت، ملكية الزيت، الكمية، ثمن الوحدة، الأداء والمتبقي، وطباعة الوصل.
- الطحن: رقم وصل تلقائي، الحصة، الزبون، الوزن، تعريفة 0.70 درهم/كلغ افتراضياً، الأداء والمتبقي، وطباعة الوصل.
- الإنتاج والحصص: ملكية إنتاج الوحدة أو الزبون، وزن الزيتون، الزيت، المرجان، الفيتور، والمردودية.
- ملفات الزبائن وكشف حساب لكل زبون.
- الموردون: سجل رئيسي، وملف تفصيلي مستقل لكل مورد يعرض مشترياته والمبالغ المؤداة والمتبقية.
- المشتريات والتوريد مع الفواتير والأداءات.
- المصاريف والصيانة والكهرباء والتعليب وقطع الغيار.
- العمال والأجور وأيام العمل والتسبيقات.
- المخزون وحركاته وأرصدة الزيت حسب ملكية الوحدة أو الزبون.
- الصندوق: حركات قبض وصرف آلية عند تسجيل المقبوضات والمدفوعات في المبيعات والطحن والمشتريات والمصاريف والأجور.
- التقارير والملخصات المالية والإنتاجية.
- النسخ الاحتياطي الكامل بصيغة JSON والاسترجاع، مع حفظ مباشر إلى وسيط USB عند دعم المتصفح.
- تصدير واستيراد بيانات جميع الأقسام بصيغة Excel XML Spreadsheet 2003.
- تجهيز تذكير بمستحقات الزبون عبر WhatsApp من كشف الحساب، مع الإرسال اليدوي بعد المراجعة.
- ترحيل مبدئي لسجلات الإصدار الأول إن كانت قاعدة بياناته متاحة في المتصفح نفسه.

## قواعد الربط
- تسجيل إنتاج زيت الوحدة يضيف كمية إلى مخزون الوحدة.
- تسجيل إنتاج الزبون يضيف الكمية إلى رصيد ذلك الزبون.
- بيع زيت الوحدة أو زيت الزبون ينشئ حركة خروج من رصيد المالك المحدد.
- المبالغ المؤداة في عمليات البيع والطحن والمشتريات والمصاريف والأجور تنشئ حركات مقابلة في سجل الصندوق.
- التعديل يعيد بناء الحركات الآلية المرتبطة بالسجل، والحذف يزيلها.

## حدود يجب الانتباه إليها قبل الاعتماد المحاسبي
- النظام محلي على متصفح/جهاز واحد. لا يوجد حالياً تسجيل دخول أو صلاحيات متعددة أو مزامنة هاتف-حاسوب.
- يجب أخذ نسخة احتياطية دورية؛ مسح بيانات المتصفح أو فقدان الجهاز قد يؤدي إلى فقدان قاعدة البيانات المحلية.
- أرصدة المخزون مشتقة من الحركات المسجلة، ويجب إدخال رصيد افتتاحي لكل مادة قبل بدء الاستخدام الفعلي. لا يمنع الإصدار الحالي تسجيل بيع يتجاوز الرصيد؛ راجع الرصيد قبل اعتماد العملية.
- الصندوق يجمع حركات القبض والصرف المسجلة، لكنه ليس بعد تسوية بنكية أو دفتر يومية مزدوج القيد، ويجب مراجعة طرق الأداء والتحويلات.
- التقرير يعرض هامشاً أولياً وليس ربحاً محاسبياً نهائياً. لم يكتمل بعد توزيع تكاليف الكهرباء والصيانة والتعليب والأجور على كل حصة/لتر، ولا معالجة المخزون الافتتاحي والختامي والضرائب والإهتلاكات.
- عند إدخال مشتريات المواد ثم تسجيل مصروف مرتبط بها، تجنب تسجيل نفس التكلفة مرتين في التقارير.
- لا يعتبر البرنامج بديلاً عن محاسب أو نظام محاسبي قانوني معتمد.

## قبل التشغيل الفعلي
أنشئ نسخة احتياطية، أدخل الموردين والزبائن والعمال، سجّل أرصدة المخزون الافتتاحية، ثم اختبر عملية بيع وطحن ومشتريات بمبالغ تجريبية وتحقق من الصندوق وكشوف الحساب والمخزون.


## ميزات التبادل والنسخ
- Excel: من الإعدادات، صدّر ملف XML Spreadsheet 2003 الذي يضم ورقة لكل قسم. بعد التعديل، أعد استيراده؛ الاستيراد يستبدل سجلات الأقسام الموجودة في الملف. ملفات XLSX الحديثة تحتاج حفظاً بصيغة XML Spreadsheet 2003 قبل الاستيراد.
- USB: استخدم زر «حفظ نسخة على USB». إذا لم يدعم المتصفح اختيار موقع الحفظ، سينزّل ملف JSON ويجب نسخه يدوياً إلى ذاكرة USB.
- WhatsApp: من كشف حساب الزبون، جهّز رسالة بالمستحقات المتبقية؛ يفتح التطبيق محادثة برسالة جاهزة ولا يرسلها تلقائياً.
